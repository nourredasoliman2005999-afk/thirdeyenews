# العين الثالثة | THIRD EYE NEWS

واجهة أولية لصحيفة العين الثالثة، باللغة العربية واتجاه RTL.

## محتويات المشروع
- `index.html`: الصفحة الرئيسية.
- `styles.css`: التصميم المتجاوب.
- `script.js`: تفاعل القائمة والبحث.
- `assets/logo.png`: ضع شعار الصحيفة هنا باسم `logo.png`.

## النشر على Cloudflare Pages
هذه نسخة واجهة ثابتة (Static Frontend) مناسبة للمعاينة الأولية:
1. ارفع محتويات هذا المجلد إلى مستودع GitHub `thirdeyenews`.
2. من Cloudflare اختر Workers & Pages ثم Create application ثم Pages ثم Connect to Git.
3. اختر مستودع `thirdeyenews`.
4. اترك Build command فارغًا، واجعل Build output directory هو `/` أو `.` حسب واجهة الإعداد.
5. انشر المشروع.

## ملاحظات مهمة
هذه نسخة واجهة أولية فقط وليست نظام صحيفة مكتملًا. الأخبار المعروضة تجريبية، والبحث يعمل داخل الأخبار الظاهرة فقط. لا توجد حتى الآن قاعدة بيانات أو لوحة إدارة آمنة أو تسجيل دخول أو رفع أخبار. يجب تنفيذ هذه الأجزاء وربطها بخدمة خلفية مثل Supabase قبل الاستخدام الفعلي أو استقبال مساهمات المحررين.
